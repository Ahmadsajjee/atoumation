## 📋 Available Workflows

### 1. **Hello World** 👋
- Simple test workflow that prints a message
- Triggered: On push to main
- No inputs needed

### 2. **Send Email** 📧
- Send emails with custom subject and body
- Triggered: Manual (via "Run workflow" button)
- **Requires:** Gmail credentials set in GitHub Secrets
  - `GMAIL_ADDRESS` - Your Gmail address
  - `GMAIL_APP_PASSWORD` - Gmail App Password

**How to set up Gmail:**
1. Go to https://myaccount.google.com/security
2. Enable 2-Step Verification
3. Search for "App passwords"
4. Select Mail and Windows Computer
5. Copy the 16-character password
6. Add to GitHub Secrets (Settings → Secrets and variables → Actions)

### 3. **Create Folder** 📁
- Create folders in your repository
- Triggered: Manual (via "Run workflow" button)
- **Input:** Folder name
